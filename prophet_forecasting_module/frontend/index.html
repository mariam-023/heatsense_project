ℹ️ About the Prophet Forecasting Engine

  • Model Architecture: Meta Prophet model configured with yearly seasonality and linear trend extrapolation.
  • Orbital Drift Correction: Includes a $+0.21^\circ\text{C}/\text{year}$ correction factor since 2010 to account for MODIS Terra satellite overpass drift.
  • Physical Bounds: Predictions are clipped to $[15.0^\circ\text{C}, 50.0^\circ\text{C}]$ to prevent unrealistic long-term temperature runaway.
  • API Integration: Fetches forecast data from /api/forecast and can be embedded in any target web application.
